# Pengujian Digital: Web AI Client

Repositori ini berisi kode pengujian untuk mengintegrasikan antarmuka web (Frontend) dengan layanan OpenRouter melalui arsitektur Serverless Backend (Vercel). Didesain oleh INDRAYAZA. Z, S.E.

## Cara Melakukan Deployment (Vercel)
1. *Push* seluruh repositori ini ke GitHub Anda.
2. Buka [Vercel](https://vercel.com) dan buat proyek baru (*Import* repositori ini).
3. Buka menu **Environment Variables** di Vercel sebelum mengklik Deploy.
4. Tambahkan *Key* bernama `OPENROUTER_API_KEY` dan isi *Value* dengan API Key Anda yang valid.
5. Klik **Deploy**. Website sudah siap digunakan secara aman!
